# DesktopReplay

Замена NVIDIA Instant Replay для Windows 10/11 с видеокартой NVIDIA: экран постоянно пишется в буфер на диске, и по горячей клавише сохраняются последние N минут. Каждый звук пишется на свою дорожку.

## Возможности

- **Мгновенный повтор:** `Alt+F10` сохраняет последние 2 минуты (длина настраивается).
- **Обычная запись:** `Alt+F9` старт/стоп. Пишется в MKV (не портится при сбое), затем перепаковывается в MP4 без перекодирования.
- **Скриншот:** `Alt+F1`, PNG или JPG.
- **Оверлей:** `Ctrl+Alt+Z` или клик по иконке в трее. В нём весь интерфейс и настройки.
- **Пять звуковых дорожек:**
  1. всё вместе (её проигрывают Discord, Telegram и браузеры);
  2. игра / активное приложение (при Alt+Tab остаётся на игре);
  3. микрофон (push-to-talk / push-to-mute, шумоподавление);
  4. системные звуки, без игры и Discord;
  5. Discord.
- **Несколько мониторов:** на каждый выбранный монитор пишется отдельный файл.
- **Окна-исключения:** окна выбранных программ (например, менеджера паролей) закрашиваются чёрным.
- **Лимит папки записей:** при заполнении (по умолчанию 75%) появляется предупреждение, сколько места и минут записи осталось. Файлы автоматически не удаляются.
- Подпапки и имена файлов по игре: `Игра_2026-11-18_21-30-05.mp4`.
- Автозагрузка, интерфейс на RU и EN, установщик и автообновление из GitHub Releases.
- Оверлей и уведомления никогда не попадают в запись.

## Как это устроено

| Часть | Технология |
|---|---|
| Захват экрана | Windows.Graphics.Capture → Direct3D 11 |
| Масштаб и цвет | D3D11 Video Processor (BGRA → NV12, BT.709), всё на GPU |
| Кодирование видео | NVENC через FFmpeg (H.264 / HEVC / AV1), кадры не копируются через CPU |
| Звук | WASAPI: захват отдельных процессов (process loopback) и микрофона, микшер 48 кГц, AAC |
| Буфер повтора | Кольцевой буфер из 2-секундных сегментов закодированных пакетов на диске |
| Интерфейс | WPF (.NET 10), трей, глобальные горячие клавиши |
| Установка и обновления | Velopack + GitHub Releases |

Сохранение повтора не перекодирует видео, а склеивает уже готовые пакеты, поэтому занимает доли секунды.

## Разработка

Нужны .NET 10 SDK и Windows 10 2004+ / 11.

```bash
dotnet build
```

```bash
src/DesktopReplay/bin/Debug/net10.0-windows10.0.22621.0/win-x64/DesktopReplay.exe --selftest
```

`--selftest` проверяет движок целиком: буфер, сохранение повтора, запись, скриншот. Отчёт пишется в `%TEMP%\DesktopReplaySelfTest\selftest.txt`.

Другие флаги запуска:
- `--minimized` — запуск в трей (так стартует автозагрузка);
- `--debug-ui` — оверлей виден на скриншотах (для разработки).

Логи лежат в `%LOCALAPPDATA%\DesktopReplay\logs`, настройки в `%APPDATA%\DesktopReplay\settings.json`.

## Релиз

Локальная сборка установщика в `Releases/`:

```bash
powershell -File tools/release.ps1 -Version 0.1.0
```

Публикация: отправьте тег `vX.Y.Z` в GitHub, и workflow `.github/workflows/release.yml` соберёт установщик и выложит релиз. Установленные копии обновятся сами.

## Известные ограничения

- Оверлей виден только в оконном и borderless-режиме. В эксклюзивном полноэкранном режиме он не появится: для этого нужно внедряться в игру, а это небезопасно с античитами. Запись при этом работает в любом режиме.
- Если включён NVIDIA Overlay, он занимает `Alt+F10` / `Alt+F9` / `Alt+F1`. DesktopReplay тогда перехватывает клавиатуру сам, но лучше отключить горячие клавиши (или весь оверлей) в NVIDIA App.
- Если игра запущена от имени администратора, глобальные клавиши через перехват клавиатуры в ней могут не срабатывать (это защита Windows). Помогает освободить сочетания от NVIDIA или запустить DesktopReplay тоже от администратора.
- Системные звуки Windows (уведомления) отдельно не пишутся: Windows не позволяет захватить их по процессу.
