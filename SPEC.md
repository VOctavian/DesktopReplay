# DesktopReplay — техническое задание

Замена NVIDIA Overlay Instant Replay. Windows 10 2004+ / Windows 11, видеокарта NVIDIA.

## 1. Режимы записи
| Режим | Хоткей по умолчанию | Описание |
|---|---|---|
| Повтор (replay) — вкл/выкл | `Alt+Shift+F10` | Буфер пишется всегда, пока функция включена |
| Сохранить повтор | `Alt+F10` | Сохраняет последние N минут (по умолчанию **2 мин**) |
| Обычная запись старт/стоп | `Alt+F9` | Независимо от буфера |
| Скриншот | `Alt+F1` | PNG (опция: JPG) |
| Оверлей | `Ctrl+Alt+Z` | Весь интерфейс и настройки |
| Push-to-talk / push-to-mute | не задан | Только для дорожки микрофона |

Все хоткеи переназначаются. Глобальные, должны работать в играх (RegisterHotKey + low-level hook как резерв). Конфликт хоткеев → предупреждение в настройках.

## 2. Видео
- **Буфер на диске**: кольцевой буфер из сегментов (~2 с, ключевой кадр на каждый сегмент) во временной папке (настраивается). При сохранении сегменты склеиваются без перекодирования.
- **Мониторы**: выбор одного или нескольких. Несколько мониторов → отдельный видеофайл на каждый (один набор аудиодорожек дублируется в оба).
- **FPS**: по умолчанию **30**; варианты 24/30/60/120/144/нативная частота.
- **Разрешение**: по умолчанию как у источника; варианты 2160p/1440p/1080p/720p (с уменьшением).
- **Кодек** (NVENC, по умолчанию **H.264**):
  - H.264 — максимальная совместимость (Discord, Telegram, браузеры, любой редактор). Файлы больше.
  - HEVC (H.265) — ~30–40% меньше файл при том же качестве; не везде проигрывается в браузере/Discord.
  - AV1 — ещё ~20% эффективнее HEVC; только RTX 40xx и новее, поддержка в редакторах хуже.
- **Качество** (по умолчанию «Высокое»): пресеты Низкое/Среднее/Высокое/Максимум/Своё (битрейт или CQ). В настройках — подсказка, сколько МБ занимает минута записи.
- **Курсор**: записывать (по умолчанию да).
- **HDR**: выкл по умолчанию; опция «HDR → SDR тональная компрессия».
- **Окна-исключения**: список процессов/окон (напр. менеджер паролей) — закрашиваются чёрным в записи.

## 3. Аудио — дорожки (фиксированный порядок)
| # | Дорожка | Источник |
|---|---|---|
| 1 | **Всё вместе** (смесь 2–5) | — первой, чтобы Discord/Telegram/браузеры проигрывали полный звук |
| 2 | Активное приложение | Process loopback (include) процесса игры/активного окна |
| 3 | Микрофон | WASAPI capture выбранного устройства |
| 4 | Системные звуки | Все аудиосессии, **кроме** активного приложения и Discord |
| 5 | Discord | Process loopback дерева процессов Discord (если не запущен — тишина) |

- Количество и порядок дорожек всегда одинаковы (удобно для монтажа); пустая дорожка = тишина.
- Громкость каждой дорожки отдельно; включение/выключение дорожки в смеси.
- Микрофон: push-to-talk / push-to-mute / всегда вкл; шумоподавление (RNNoise) вкл/выкл.
- Кодек аудио: AAC 192 kbps (опция 128/256/320).

## 4. Файлы
- Запись в **MKV** (устойчив к сбоям) → сразу **ремукс в MP4** без перекодирования; MKV удаляется после успешного ремукса (опция: оставлять MKV).
- Имя: `Игра_2026-11-18_21-30-05.mp4`, подпапки по играм. Несколько мониторов → суффикс `_mon1`, `_mon2`.
- Название игры: описание файла процесса → заголовок окна → имя exe. Нет приложения → `Desktop`.
- Папка сохранения настраивается.
- **Лимит размера папки**: файлы **не удаляются автоматически**. При ≥ 75% — уведомление при каждом сохранении/записи: «Занято X из Y ГБ, осталось Z ГБ (~N минут записи)». При 100% — предупреждение.

## 5. Интерфейс
- Иконка в трее (меню: открыть оверлей, вкл/выкл повтор, сохранить повтор, начать запись, открыть папку, выход). Индикатор состояния: буфер активен / идёт запись.
- **Оверлей** — полупрозрачное окно поверх всех окон, работает в оконном и borderless-режиме (без инжекта в игру — безопасно для античитов). Содержит: статус, быстрые кнопки, все настройки.
- Уведомления: звук и/или всплывающее окно «Клип сохранён» / «Скриншот сохранён» / «Запись начата/остановлена» (каждое настраивается).
- Языки: RU / EN.
- У каждой настройки с вариантами — пояснение, в чём разница.

## 6. Система
- Автозагрузка с Windows (по умолчанию вкл), старт свернутым в трей.
- Установщик + автообновление из **GitHub Releases**.
- Логи в `%LOCALAPPDATA%\DesktopReplay\logs`.

## 7. Не входит в v1
- Галерея и обрезка клипов.
- Оверлей поверх эксклюзивного полноэкранного режима (требует инжекта).

## Решения
- Стек: C# / .NET 10 + WPF, свой движок: Windows.Graphics.Capture + D3D11 + FFmpeg (NVENC) + WASAPI.
- Дорожка 2 при Alt+Tab остаётся на игре (полноэкранное приложение «прилипает», пока не закроется). Без игры дорожка следует за активным окном.
- Репозиторий GitHub публичный, автообновление из GitHub Releases (Velopack).
- Повтор сохраняется сразу в MP4 (из готовых пакетов буфера). MKV → MP4 используется только для обычной записи.
